# Security

## Reporting

Report vulnerabilities privately to **info@parallexlabs.ca**. Do not open public issues for security reports.

## Scope

Source Check Lab is a static client-side web app. User text should remain in browser memory only. If you find code that exfiltrates pasted content, please report it.

## Models

Optional models download from Hugging Face when the user explicitly requests them. Verify CSP and network behaviour if you file a report.
